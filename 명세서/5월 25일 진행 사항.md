# 2026-05-25 진행 사항

## 1. 현재 빌드 상태

- Debug x64 빌드 성공 확인.
- Editor 렌더 버그는 별도 검수까지 완료된 상태로 보고, 후속 작업은 VFX/Shader 확장으로 이동한다.
- FMOD 기반 Sound Manager와 BGM/SFX 재생 연결은 구현 완료 상태로 정리한다.

## 2. FMOD Sound/BGM

- Engine 소유 Sound Manager와 `CGameInstance` 위임 API를 통해 Client/GameApp/Editor가 직접 FMOD API에 의존하지 않는 구조로 정리했다.
- BGM 재생, SFX 재생, 정지, 볼륨 제어 흐름이 연결되었다.
- 수업 코드 적용 명세서에서 FMOD는 Shadow/NormalMap 진입 전 완료 항목으로 이동한다.

## 3. SceneData 기반 Torch PointLight/VFX

- Editor에서 SceneData에 저장한 LightData를 SSOT로 사용한다.
- `Torch_` 이름을 가진 PointLight 좌표를 모아 `CAtlasInstanceEffect`의 instance 위치로 사용한다.
- 일반 PointLight와 Torch VFX는 이름 prefix로 분리한다. 모든 PointLight를 Torch로 취급하지 않는다.
- Torch quick slot은 이름만 바꾸고 색상/Range 등 사용자가 조정한 값은 덮어쓰지 않도록 정리했다.
- Torch Light의 Y 위치는 기존 저장값 기준 `+0.5f` 보정 상태다.

## 4. Atlas Instance Fire Effect

- `CVIBuffer_Instance` / `CVIBuffer_Rect_Instance` 기반 atlas billboard effect 인프라를 추가했다.
- `CAtlasInstanceEffect`는 Torch 전용 오브젝트가 아니라 texture prototype tag, position list, atlas frame 정보를 받는 범용 effect 오브젝트로 둔다.
- Fire atlas texture는 `Resources/Textures/Effect/Fire/Fx_Fire_Atlas.png`를 사용한다.
- `Shader_VtxRectInstance.hlsl`에는 범용 alpha pass `Atlas_Instance`와, 불꽃용 additive pass `Atlas_Instance_Additive`를 분리했다.
- 불꽃 pass는 black 근접 픽셀을 threshold discard하고 additive blend로 출력한다. 원본 PNG 자체는 유지하고 shader에서 배경을 제거한다.
- Torch effect는 `ATLAS_INSTANCE_EFFECT_DESC::iShaderPass = 1`로 additive pass를 사용한다.

## 5. 리소스 등록 점검

- `Loader.cpp`의 `Prototype_Component_Texture_BackGround`는 `CBackGround`가 현재 런타임에서 생성되지 않는다면 사용되지 않는다.
- `Default%d.jpg`를 삭제한 상태라면 해당 prototype 등록은 제거해도 현재 GamePlay 흐름에는 영향이 낮다.
- 단, 추후 Logo/BackGround 오브젝트를 되살릴 경우에는 별도 배경 텍스처를 다시 등록해야 한다.
